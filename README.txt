Fallen Star — source bundle

Unzip this folder and keep index.html and the assets folder together.
Open index.html in a modern browser. Tap “Tap to begin” to start the music.

The page styles and interactions are in index.html. Scene timing is editable
in the SCENE_CUES array near the bottom of that file. The included background
image and music track are used from the assets folder.

The typefaces load from Google Fonts when online; system fallbacks are included.
